# notizie-ai

Brief quotidiano di notizie AI, pubblicato automaticamente ogni mattina.

- Sito: https://tomci79-instinct.github.io/notizie-ai/
- `index.html` — brief del giorno con archivio
- `data/notizie-ai-YYYY-MM-DD.json` — dati strutturati di ogni giorno
- `tools/` — template e script di rendering

Generato da Instinct per Tommaso.
